A little about Atelier.

A student project with a simple idea: make art feel approachable, one page at a time.

The idea behind the gallery

Room for
a new perspective.

Atelier began as an online gallery for a web development course. We chose art because a gallery gives color, typography, and layout room to tell a story.

The collection uses original geometric illustrations. The artist profiles and exhibition themes are fictional, created to make the gallery feel connected and easy to explore.

Built with the basics

Atelier uses HTML, CSS, Bootstrap, JavaScript, and jQuery. The final project adds a theme switch, a browser sign-in demo, an FAQ, and a museum collection search.

Frequently asked questions

The six illustrated works were created for the student project. Mira Arden, Noah Vale, and Lena Sol are fictional artist personas.

Select an artwork in the Atelier collection to open its viewer. Use the arrow keys to browse and Escape to close.

The exhibition planner saves your changes in this browser. Use the same browser and website address to see them again.

The Cleveland Museum of Art provides the records. Open a result title to see the museum's full artwork record and credit.

Browsing is open to everyone. The optional sign-in demo saves a display name so the account page can greet you when you return.
